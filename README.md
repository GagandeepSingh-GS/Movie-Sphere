# Movie Sphere
A Python and Streamlit-based movie search and recommendation system for discovering movies and exploring recommendations.

## Features

- Search for movies
- Get movie recommendations
- View movie details
- Explore movie posters, ratings, and cast information

## Technologies

- Python
- Streamlit
- Pandas
- scikit-learn
- OMDb API

## Project Structure

- `app.py` — Main Streamlit application
- `data/` — Movie dataset
- `utils/` — Movie API-related code
